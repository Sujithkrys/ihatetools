## Why Page Deletion Belongs in Your Browser, Not on a Server

A PDF page removal tool only needs to touch the document's internal page tree, nothing more, so there's no technical reason it should ever leave your device. When you run this process through a server-based tool, your file sits in someone else's storage, however briefly, and you have no real way to confirm it was deleted afterward. For documents like leases, medical records, or internal reports, that's an unnecessary exposure for a task this simple.

Doing it in the browser also means there's no file size cap forcing you into a "Pro" plan, and no wait while a page spins through an upload queue. The PDF is parsed, pages are removed, and the file is rebuilt, all using your device's own processing power.

## Best Practices for Cleaning Up PDFs

- **Check for page numbers printed inside the content.** Deleting a page only removes it from the file structure; it won't renumber any "Page 5 of 40" text that was typed into the document itself. If you need that fixed, run the result through the [Add Page Numbers tool](/tools/add-page-numbers) afterward to overwrite the old numbering.
- **Review double-sided scans carefully.** If your PDF came from a duplex scanner, a "blank" page might actually be intentional (the back of a printed sheet). Zoom into the thumbnail before deleting to avoid breaking a page-pairing structure some print shops expect.
- **Delete before you sign.** If a document still needs a signature, remove unnecessary pages first with the [Delete PDF Pages tool](/tools/delete-pdf-pages), then move to the [Sign PDF tool](/tools/sign-pdf). Signing after editing avoids invalidating a signature that references the old page count.
- **Keep an untouched copy.** Page deletion isn't reversible once you've overwritten the original file, so save your source PDF somewhere safe before editing, especially for legal or academic documents.
